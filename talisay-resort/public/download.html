Talisay Beach Resort

Install the guest app on your Android phone. It uses the same website and database as the resort system.

Download the Android app (version 1.1.0)
  1. Open this page in Chrome. If it opened inside Facebook or Messenger, tap the menu and choose Open in Chrome first.
  2. Tap the download button and wait until the file finishes.
  3. Open the downloaded file and allow installs from Chrome if Android asks.
  4. Sign in or create an account. Rooms and bookings are saved in the resort database.
